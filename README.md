# Dual Sleeper v1.4.0 (デュアル・スリーパー)

**最新バージョン:** `v1.4.0` (2026-08-02 リリース)

**Dual Sleeper** は、`run.bat` をダブルクリックして起動するだけで、放置時にPCを段階的に自動スリープさせ、周辺の雷発生時に休止状態へ自動退避させるインテリジェント電源・防犯・サーバー管理ツールです。

特別なインストール作業やアカウント登録を行わなくても、バックグラウンドで起動しておくだけでユーザーの離席・未登録動画・ゲームサーバー接続・通話・AI学習・大容量通信・CPU高負荷（Windows Update含む）・周辺の落雷発生を全自動で判定し、画面消灯・スリープおよび休止保護を全自動で実行します。

※スマホへの通知や遠隔操作（Discord / Telegram 連携）は、必要に応じて設定できる拡張機能です。

---

## 🌟 最新バージョン v1.4.0 の新機能

### 1. 2 段構え通信判定設計 (Two-Tier Network Architecture)
* **📺 画面点灯中 / 消灯前 (State 1):**  
  未登録の動画サイト（TVer、ニコニコ、各種Web動画等）を視聴していても画面が暗くならないよう、`network_limit_kbs` (固定判定値: 30.0 KB/s) ＋ 移動中央値 (Moving Median) で通信をキャッチし、**動画バッファ通信が発生するたびに消灯タイマーをリセットして点灯を維持** します。
* **🌙 画面消灯後 / 離席中 (State 2):**  
  モニターが消灯した後は、**`動的通信上限` (ベース ＋ マージン `dynamic_network_margin_kbs`: 30.0 KB/s)** が適用されます。クラウド同期や常駐アプリの背景通信ノイズを自動学習して上限内に飲み込み、パルス通信に邪魔されずスムーズにシステムスリープへ案内します。

### 2. ⏱️ 3 秒持続確認タイマー (3-Second Debouncing)
* ミリ秒〜1秒置きに発生する「ぷっぷ」という一瞬のパルスノイズは **3秒未満のため 100% 完全無視** します。
* Immich での写真閲覧やファイル共有など、**3 秒以上連続して発生した通信のみを人間の意図した本物操作と判断** し、スリープタイマーをしっかりリセット・保護します。

### 3. 🎮 ゲームサーバー保護機能 (`game_server_protection`)
* Palworld（パルワールド）、Minecraft、HTTP（Immich等）など、指定した単一または**複数ポート（例: `ports: [8211, 2283]`）** への外部・Tailscale・LAN アドレスからのプレイヤー接続を物理検知します。
* **プレイヤー接続中 (1名以上):** **スリープを絶対無効化**（タイマーリセット固定）。遊んでいる間は100%スリープしません。
* **全員離脱・無人 (0名):** 自動で保護が解除され、**5分後に全自動でスリープして節電** します。

## ユースケースと動作仕様

日常や開発における以下のような状況を自動判定し、モニターの消灯およびPCのスリープを制御します。

1. **通常の離席時**
   * 無操作時間（デフォルト5分）でモニターを消灯し、さらに5分経過後にPC本体をスタンバイ（スリープ）にします。
2. **LINE / Discord / Zoom 等での通話時**
   * **[WASAPI オーディオセッション保護]** 通話中である限り音声ストリームを検知してスリープ移行を阻止します（モニターは消灯）。通話終了後にタイマーが再開し自動スリープします。
3. **YouTube等の動画閲覧時**
   * バッファ通信や特定ウィンドウタイトルを検知し、モニター消灯およびスリープ移行を防止します。
4. **大容量ファイルのダウンロード時**
   * Downloadsフォルダ内の一時ファイル（`.crdownload`, `.part`）検知により、ダウンロードが完了するまでスリープ移行を阻止します（モニターは消灯）。
5. **ゲーム起動中の放置時**
   * GPU使用率が 30% 以上であっても、保護対象プロセス（python等）に含まれない場合は放置中と判定し、スリープを実行します。
6. **ゲームプレイ＋配信等の高トラフィック時**
   * モニター消灯中であっても、配信データ（5 Mbps以上の高トラフィック）を検知した場合、スリープ移行を阻止します。
7. **NVIDIA GPUでのAI学習・推論時**
   * GPUを消費しているプロセス名が `python.exe` や `llama-server` 等に該当する場合、処理中と判定してスリープ移行を自動阻止します。
8. **CPU高負荷・Windows Update進行時**
   * 動画エンコードや **Windows Update のインストール (`TiWorker.exe`等)** で CPU 80% 以上の高負荷状態が続く間、スリープ移行を自動阻止して安全に処理を完遂させます。
9. **ゲームサーバー稼働時 (パルワールド・マイクラ等)**
   * 指定ポート (`8211`, `2283`等) への外部/Tailscale/LAN接続がある間、スリープを絶対無効化します。全員離脱で5分後に自動スリープします。
10. **離席中の急な雷雨・豪雨発生時**
    * 画面消灯中（離席中）に端末周辺で雷や豪雨が検知された場合、「休止状態（ハイバネート）」へ自動移行してPCとデータを保護します。

## はじめかた・基本の使い方 (Quick Start)

1. **ダウンロードと起動**
   * Git コマンド（`git clone https://github.com/OKPN/dual-sleeper.git`）または zip ダウンロードでファイルを取得し、フォルダ内の **`run.bat`** をダブルクリックして起動します（Python の事前インストールは不要です）。
2. **アイドル時の通信速度の確認**
   * 起動後、PCを触らず少し放置するとコンソール画面にリアルタイムの通信速度（`Median KB/s`）が表示されます。自身の環境における「放置時の平常通信速度」を確認します。
3. **設定の調整 (任意)**
   * 必要に応じて `config.json` を開き、画面消灯までの時間（`idle_limit_seconds`）や無通信と判定する速度しきい値（`network_limit_kbs`）、動的マージン（`dynamic_network_margin_kbs`）を調整します。
4. **ゲームサーバー保護を使いたい場合 (オプション)**
   * パルワールドや各種サーバーを運用する場合は、`config.json` の `"game_server_protection"` を有効化し、対象ポート番号（例: `"ports": [8211, 2283]`）を設定します。
5. **落雷保護機能（雷保護機能）を使いたい場合 (オプション)**
   * 落雷接近時の自動退避・警戒機能を利用する場合は、以下の手順で位置情報を登録します：
     1. [Google マップ](https://maps.google.com) を開き、自宅やPC設置場所の指定箇所を**右クリック**します。
     2. メニューの一番上に表示される **「緯度, 経度」**（例: `35.681234, 139.767123`）をクリックしてコピーします。
     3. `config.json` を開き、`"lightning_protection"` の `"location"` にそのまま貼り付け、`"enabled": true` に変更して保存します。
6. **そのまま放置運用**
   * 調整後はバックグラウンドで起動しておくだけで、操作・通信・通話・ゲーム・落雷発生などを全自動で判断し、省エネおよび自動保護を行います。
7. **外部通知 ＆ スマホ双方向リモート操作を行いたい場合 (オプション)**
   * スマホでの通知受信やリモート操作を行いたい場合は、以下を `config.json` に設定します：
     * **Discord Webhook (一方向通知 ＆ WoL連携):**  
       Discordサーバーのチャンネル設定 ➔「連携サービス」➔「ウェブフックを作成」してURLをコピーし、`config.json` の `"discord_webhook_url"` に貼り付けます。
     * **Telegram Bot (双方向リモート操作 ＆ 1秒応答):**  
       1. Telegramアプリで `@BotFather` を検索し、`/newbot` と送ってトークンを取得し、`"telegram_bot_token"` に設定します。
       2. Telegramで `@userinfobot` にメッセージ（または `/start`）を送ると自分のIDが一瞬で表示されるため、それを `"telegram_chat_id"` に設定します。  
       * **[できること]** スマホからコマンド（`/sleep`, `/status`, `/weather`, `/server`）を送って遠隔操作したり、通知に返信するだけでスリープを10分延期することが可能です。
8. **電源プロファイル自動切替を行いたい場合 (オプション)**
   * 状況に応じて「省電力」「高パフォーマンス」「究極のパフォーマンス」をダイナミックに自動切替したい場合は、`config.json` の `"power_plan_control"` 内の `"enabled"` を `true` に変更します（初期値は `false` / オフです）。Windows 10 / 11 の最新仕様に対応しており、カスタムプロファイルを一切生成せずOS標準プロファイルのみを切り替えるため、レジストリを汚さず100%安全にご活用いただけます。

## 電源プロファイル自動制御機能 (`power_plan_control`) の詳細

Dual Sleeper は、Windows OS の標準電源プラン（GUID）をダイナミックに自動切替し、処理性能の最大化と放置時の極限節電を自動で両立させます。

### 主な動作モード
1. **完全放置消灯時 (State 2) の全自動節電**
   * 操作から離脱してモニターが消灯（State 2）した瞬間、自動的に OS 標準の **「省電力」プロファイル** へ切り替え、CPUのクロックと電圧を物理的に抑制して消費電力を大幅カットします。
   * 復帰時（マウス移動）やアプリ終了時には、**100% 安全に「元々設定されていた電源プラン」へと自動復元** します。
2. **GPUゲーム中の高パフォーマンス昇格 (`ultimate_on_game`)**
   * ゲーム起動時（GPU使用率 30%以上）に自動的に **「究極のパフォーマンス（または高パフォーマンス）」** プランへ自動昇格し、フレームレートの低下を防ぎます。
3. **AI学習・推論時の昇格 (`high_performance_on_ai`)**
   * `python.exe` や `llama-server` 等が VRAM 4GB 以上を消費して AI 処理を行っている場合、自動的に **「高パフォーマンス」** プランへ昇格させ、PCIe 省電力モードによる生成遅延（t/s低下）を防ぎます。
4. **CPU高負荷処理時の昇格 (`high_performance_on_cpu`)**
   * 動画書き出し、エンコード、コンパイル、Windows Update 等で CPU 80% 以上が 5 秒間継続した場合、自動的に **「高パフォーマンス」** プランへ昇格させます。

## 📱 Telegram コマンド一覧

Telegram Bot から以下のコマンドを送信して、スマホから遠隔操作・状態確認が行えます：

* `/status` : 現在の状態、通信速度、**動的通信上限 (ベース ＋ マージン)**、**ゲームサーバー接続数**、GPU・電源プランをリアルタイム表示。
* `/sleep` : 次回スリープ移行時の挙動をトグル切り替え（`スリープ` / `休止状態` / `自動`）。
* `/server` : 高速消灯サーバーモードの切替（`オフ` / `デスクトップ時` / `常時`）。
* `/weather` : 端末周辺の現在の気象・落雷警報状況および 12時間 CAPE 雷予報を表示。

## バージョン履歴 (Changelog)

### v1.4.0 (2026-08-02)
* **2 段構え通信判定設計 (Two-Tier Architecture):**  
  消灯前(State 1)は未登録動画の点灯維持用固定しきい値 (`network_limit_kbs`: 30 KB/s)、消灯中(State 2)は背景ノイズ自動吸収用の動的上限 (`ベース ＋ マージン`) に役割を完全分離。
* **3 秒持続確認タイマー (3-Second Debouncing):**  
  ミリ秒〜1秒の「ぷっぷ」というパルスノイズを100%無視し、Immich等の 3秒以上持続した操作通信のみを確実に検知してスリープタイマーをリセット。
* **ゲームサーバー保護機能 (`game_server_protection`):**  
  Palworld、Minecraft、HTTP 等、複数ポート（`ports: [8211, 2283]`）の外部/Tailscale/LAN 接続を物理検知。プレイヤー接続中はスリープを絶対無効化、全員離脱で5分後に自動スリープ。
* **用語の統一:**  
  動的通信上限の内訳表現を直感的な「ベース」と「マージン」に完全統一。
* **スリープ決定時通知の強化:**  
  スリープ移行前の予告通知メッセージ内に、スリープ決定時点の動的通信上限とゲームサーバー接続状況を記録表示。

### v1.3.0 (2026-07-29)
* **トリプルハイブリッド動的通信上限エンジンの導入:**  
  移動中央値 (Moving Median) と下位サンプルによる「平常時ベースライン自動学習」を導入。
* **ダイアログ拒否時の強制スリープ機能 (`force_sleep_on_dialog`):**  
  保存確認ダイアログ等でスリープ拒否された際、強制的にスリープへ移行させる設定を追加。

### v1.2.3 (2026-07-28)
* **`/status` 残りカウントダウン計算の正確性修正:** 無操作残り時間と低通信判定時間を正しく合算した「消灯まで残り: X分X秒」を出力するロジックへ修復。
* **`/weather` レポートへのリアルタイム降水量 (`mm/h`) 併記:** 雨・雷雨等の場合、自動で `(降水量: X.X mm/h)` を併記。
