# Dual Sleeper v1.4.0 (デュアル・スリーパー)

**最新バージョン:** `v1.4.0` (2026-08-02 リリース)

**Dual Sleeper** は、`run.bat` をダブルクリックして起動するだけで、放置時にPCを段階的に自動スリープさせ、周辺の雷発生時に休止状態へ自動退避させるインテリジェント電源・防犯管理ツールです。

特別なインストール作業やアカウント登録を行わなくても、バックグラウンドで起動しておくだけでユーザーの離席・未登録動画・ゲームサーバー接続・通話・AI学習・CPU高負荷（Windows Update含む）・周辺の落雷発生を判定し、画面消灯・スリープおよび休止保護を全自動で実行します。

※スマホへの通知や遠隔操作（Discord / Telegram 連携）は、必要に応じて設定できる拡張機能です。

---

## 🌟 主要機能と動作仕様

日常や開発、ゲームサーバー運用における以下のような状況を自動判定し、モニター消灯およびPCシステムのスリープを最適なアルゴリズムで制御します。

### 1. 2 段構え通信判定設計 (Two-Tier Network Architecture)
* **📺 画面点灯中 / 消灯前 (State 1):**  
  未登録の動画サイト（TVer、ニコニコ、各種Web動画等）を視聴していても画面が暗くならないよう、`network_limit_kbs` (固定判定値: 30.0 KB/s) ＋ 移動中央値 (Moving Median) で通信をキャッチし、**動画バッファ通信が発生するたびに消灯タイマーをリセットして点灯を維持** します。
* **🌙 画面消灯後 / 離席中 (State 2):**  
  モニターが消灯した後は、**`動的通信上限` (ベース ＋ マージン `dynamic_network_margin_kbs`: 30.0 KB/s)** が適用されます。クラウド同期や常駐アプリの背景通信ノイズを自動学習して上限内に飲み込み、パルス通信に邪魔されずスムーズにシステムスリープへ案内します。

### 2. ⏱️ 3 秒持続確認タイマー (3-Second Debouncing)
* ミリ秒〜1秒置きに発生する「ぷっぷ」という一瞬のパルスノイズは **3秒未満のため 100% 完全無視** します。
* Immich での写真閲覧やファイル共有など、**3 秒以上連続して発生した通信のみを人間の意図した本物操作と判断** し、スリープタイマーをしっかりリセット・保護します。

### 3. 🎮 ゲームサーバー保護機能 (`game_server_protection`)
* Palworld（パルワールド）、Minecraft、HTTP（Immich等）など、指定した単一または**複数ポート（例: `ports: [8211, 2283]`）** への外部・Tailscale・LAN アドレスからのプレイヤー接続を物理検知します。
* **プレイヤー接続中 (1名以上):** **スリープを絶対無効化**（タイマーリセット固定）。遊んでいる間は100%スリープしません。
* **全員離脱・無人 (0名):** 自動で保護が解除され、**5分後に全自動でスリープして節電** します。

### 4. ⚙️ AI学習・CPU高負荷・Windows Update 安全保護
* **NVIDIA GPU 監視:** `python.exe` や `llama-server` 等の指定AIプロセスが VRAM を消費して推論・学習中である場合、スリープを全自動で阻止します。
* **CPU 高負荷保護:** 重いコンパイル処理や **Windows Update のインストール処理 (`TiWorker.exe`等)** で CPU 使用率が 80% 以上になっている間、スリープを自動ストップして安全に処理を完了させます。

### 5. 🎙️ WASAPI 通話保護 ＆ 大容量ダウンロード保護
* **LINE / Discord / Zoom 通話中:** 音声ストリームを直接検出してスリープ移行を阻止します（画面は暗く省エネ維持）。通話終了後にタイマーが再開します。
* **ブラウザダウンロード:** `Downloads` フォルダ内の一時ファイル（`.crdownload`, `.part`）を検知し、完了までスリープを延期します。

### 6. 🌩️ 落雷保護アラート (Open-Meteo 連動)
* 画面消灯中（離席中）にPC周辺で雷や豪雨、またはCAPE雷エネルギー予報が上昇した場合、自動的に「休止状態（S4: 電源OFF）」へ退避し、PCとデータを過電圧から保護します。

### 7. 📱 Telegram Bot リアルタイムステータス ＆ スマホリモート制御
* スマホの Telegram Bot から `/status` を送るだけで、**現在の状態・リアルタイム通信速度・動的上限（ベース ＋ マージン）・ゲームサーバー接続状況** が一目で確認できます。
* スリープ直前の 30 秒予告通知に何か1文字送るだけで、スマホから 10 分間スリープを遠隔延長できます。

## ⚙️ 設定ファイル仕様 (`config.json`)

`config.json` の各パラメータの説明一覧です：

| 分類 | パラメータ名 | 初期値 | 単位 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| **放置判定** | `idle_limit_seconds` | `120` | 秒 | 物理的な無操作（キー・マウス）で消灯判定を開始する時間。 |
| | `network_check_duration_seconds` | `30` | 秒 | 放置判定のため通信速度を集計・監視する秒数。 |
| | `standby_after_monitor_off_seconds` | `300` | 秒 | モニター消灯(State 2)後、システムがスリープするまでの待機時間。 |
| **通信判定** | `network_limit_kbs` | `30.0` | KB/s | **消灯前(State 1)** の通信判定しきい値（未登録動画の点灯維持用）。 |
| | `dynamic_network_margin_kbs` | `30.0` | KB/s | **消灯中(State 2)** の動的ベースライン通信量に加算するマージン速度。 |
| | `high_network_limit_kbs` | `625.0` | KB/s | 配信中などの高トラフィックとみなす保護しきい値（5 Mbps相当）。 |
| **ゲーム保護** | `game_server_protection.enabled` | `false` | bool | ゲームサーバーポート保護機能の有効/無効（初期値: 無効）。 |
| | `game_server_protection.ports` | `[8211, 2283]` | 配列/数値 | プレイヤー接続を物理監視する対象ポート番号リスト。 |
| **電源制御** | `power_plan_control.enabled` | `true` | bool | Windows電源プラン（省電力/バランス/高パフォーマンス）自動切替。 |
| | `power_plan_control.cpu_heavy_threshold_percent` | `80` | % | CPU高負荷保護（Windows Update等）を発動する使用率しきい値。 |
| **GPU保護** | `gpu_protect_processes` | `["python.exe", ...]` | リスト | AI学習・推論など保護対象とするGPUプロセス名一覧。 |
| | `gpu_protect_min_vram_mb` | `4000` | MB | AI保護プロセスが処理中か判断する最小VRAM消費量しきい値。 |
| **サーバモード**| `server_mode` | `"off"` | 文字列 | 高速画面消灯サーバモード（`"off"`, `"desktop"`, `"always"`）。 |
| | `server_mode_standby_delay_seconds` | `600` | 秒 | サーバモード時にモニター消灯後スリープするまでの遅延秒数。 |
| **落雷保護** | `lightning_protection.enabled` | `false` | bool | 近隣の落雷・豪雨接近時の自動休止状態退避機能。 |
| | `lightning_protection.location` | `"35.6812, 139.7671"` | 緯度,経度 | PC設置場所の Google マップ座標。 |
| **通知・遠隔** | `telegram_bot_token` / `chat_id` | `""` / `""` | 文字列 | Telegram Bot 連携トークン ＆ チャットID。 |

## 📱 Telegram コマンド一覧

Telegram Bot から以下のコマンドを送信して、スマホから遠隔操作・状態確認が行えます：

* `/status` : 現在の状態、通信速度、**動的通信上限 (ベース ＋ マージン)**、**ゲームサーバー接続数**、GPU・電源プランをリアルタイム表示。
* `/sleep` : 次回スリープ移行時の挙動をトグル切り替え（`スリープ` / `休止状態` / `自動`）。
* `/server` : 高速消灯サーバーモードの切替（`オフ` / `デスクトップ時` / `常時`）。
* `/weather` : 端末周辺の現在の気象・落雷警報状況および 12時間 CAPE 雷予報を表示。
