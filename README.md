# Dual Sleeper v1.3.0 (デュアル・スリーパー)

**最新バージョン:** `v1.3.0` (2026-07-29 リリース)

**Dual Sleeper** は、`run.bat` をダブルクリックして起動するだけで、放置時にPCを段階的に自動スリープさせ、周辺の雷発生時に休止状態へ自動退避させる電源・防災管理ツールです。

インストール作業やアカウント登録、通知設定を行わなくても、バックグラウンドで起動しておくだけでユーザーの離席・ゲーム・通話・AI学習・大容量通信・周辺の雷発生を判定し、スリープおよび休止保護を実行します。

※スマホへの通知や遠隔操作（Discord / Telegram 連携）は、必要に応じて設定できる拡張機能です。

---

## ユースケースと動作仕様

日常や開発における以下のような状況を自動判定し、モニターの消灯およびPCのスリープを制御します。

1. **通常の離席時**
   * 無操作時間（デフォルト5分）でモニターを消灯し、さらに5分経過後にPC本体をスタンバイ（スリープ）にします。
2. **LINE / Discord / Zoom 等での通話時**
   * **[WASAPI オーディオセッション保護]** 通話中である限り音声ストリームを検知してスリープ移行を阻止します（モニターは消灯）。通話終了後にタイマーが再開し自動スリープします。
3. **YouTube等の動画閲覧時**
   * バッファ通信や特定ウィンドウタイトルを検知し、モニター消灯およびスリープ移行を防止します。
4. **大容量ファイルのダウンロード時**
   * Downloadsフォルダ内の一時ファイル（`.crdownload`, `.part`）検知により、ダウンロードが完了するまでスリープ移行を阻止します（モニターは消灯）。
5. **ゲーム起動中の放置時**
   * GPU使用率が 30% 以上であっても、保護対象プロセス（python等）に含まれない場合は放置中と判定し、スリープを実行します。
6. **ゲームプレイ＋配信等の高トラフィック時**
   * モニター消灯中であっても、配信データ（5 Mbps以上の高トラフィック）を検知した場合、スリープ移行を阻止します。
7. **NVIDIA GPUでのAI学習・推論時**
   * GPUを消費しているプロセス名が `python.exe` や `llama-server` 等に該当する場合、処理中と判定してスリープ移行を自動阻止します。
8. **離席中の急な雷雨・豪雨発生時**
   * 画面消灯中（離席中）に端末周辺で雷や豪雨が検知された場合、「休止状態（ハイバネート）」へ自動移行してPCとデータを保護します。

## はじめかた・基本の使い方 (Quick Start)

1. **ダウンロードと起動**
   * Git コマンド（`git clone https://github.com/OKPN/dual-sleeper.git`）または zip ダウンロードでファイルを取得し、フォルダ内の **`run.bat`** をダブルクリックして起動します（Python の事前インストールは不要です）。
2. **アイドル時の通信速度の確認**
   * 起動後、PCを触らず少し放置するとコンソール画面にリアルタイムの通信速度（`Median KB/s`）が表示されます。自身の環境における「放置時の平常通信速度」を確認します。
3. **設定の調整 (任意)**
   * 必要に応じて `config.json` を開き、画面消灯までの時間（`idle_limit_seconds`）や無通信と判定する速度しきい値（`network_limit_kbs`）を調整します。
4. **落雷保護機能（雷保護機能）を使いたい場合 (オプション)**
   * 落雷接近時の自動退避・警戒機能を利用する場合は、以下の手順で位置情報を登録します：
     1. [Google マップ](https://maps.google.com) を開き、自宅やPC設置場所の指定箇所を**右クリック**します。
     2. メニューの一番上に表示される **「緯度, 経度」**（例: `35.681234, 139.767123`）をクリックしてコピーします。
     3. `config.json` を開き、`"lightning_protection"` の `"location"` にそのまま貼り付け、`"enabled": true` に変更して保存します。
5. **そのまま放置運用**
   * 調整後はバックグラウンドで起動しておくだけで、操作・通信・通話・ゲーム・落雷発生などを全自動で判断し、省エネおよび自動保護を行います。
6. **外部通知 ＆ スマホ双方向リモート操作を行いたい場合 (オプション)**
   * スマホでの通知受信やリモート操作を行いたい場合は、以下を `config.json` に設定します：
     * **Discord Webhook (一方向通知 ＆ WoL連携):**  
       Discordサーバーのチャンネル設定 ➔「連携サービス」➔「ウェブフックを作成」してURLをコピーし、`config.json` の `"discord_webhook_url"` に貼り付けます。
     * **Telegram Bot (双方向リモート操作 ＆ 1秒応答):**  
       1. Telegramアプリで `@BotFather` を検索し、`/newbot` と送ってトークンを取得し、`"telegram_bot_token"` に設定します。
       2. Telegramで `@userinfobot` にメッセージ（または `/start`）を送ると自分のIDが一瞬で表示されるため、それを `"telegram_chat_id"` に設定します。  
       * **[できること]** スマホからコマンド（`/sleep`, `/status`, `/weather`, `/server`）を送って遠隔操作したり、通知に返信するだけでスリープを10分延期することが可能です。
7. **電源プロファイル自動切替を行いたい場合 (オプション)**
   * 状況に応じて「省電力」「高パフォーマンス」「究極のパフォーマンス」をダイナミックに自動切替したい場合は、`config.json` の `"power_plan_control"` 内の `"enabled"` を `true` に変更します（初期値は `false` / オフです）。Windows 10 / 11 の最新仕様に対応しており、カスタムプロファイルを一切生成せずOS標準プロファイルのみを切り替えるため、レジストリを汚さず100%安全にご活用いただけます。

### プライバシー ＆ セキュリティ
* **個人情報の収集・保管・外部送信は一切行いません。**
* 設定された位置情報（`location`）や通知用トークン等は、すべてローカルPC内の `config.json` にのみ保持されます。
* 位置情報は Open-Meteo 気象API への気象データ照会、通知トークンはご自身のスマホ端末への通知送信にのみ限定使用され、第三者のサーバー等へ送出されることはありません。

## 主な機能

### 1. [全自動・利用状況判別] 状況に応じたスマートな省電力・消灯制御
* **利用状況の全自動識別:**  
  PCの操作有無だけでなく、通話（LINE/Discord/Zoom等）・動画試聴（YouTube等）・放置ゲーム・大容量ダウンロード・AI処理などをリアルタイムに識別し、状況に応じて「モニター消灯のみ」や「スリープ阻止」、「スリープ/休止状態実行」を全自動で最適制御します。
* **オーディオ・通話保護:**  
  Windowsの内部オーディオセッションを常時監視し、マイクやスピーカーの音声ストリームがアクティブな場合は通話が終了するまでスリープ移行を阻止します（モニターは消灯）。
* **重要作業の中断防止:**  
  大容量ダウンロード中やレンダリング・AI学習中、配信中などの重要作業を誤ってスリープで中断させません。

### 2. [落雷自動保護] 離席中の自動休止移行 ＆ 先回り警戒
* **西側優先スキャン:**  
  日本の気象特性に合わせて西側に観測エリアを多く配置することで、接近する雷をいち早くキャッチして事前警戒を行います。
* **離席中の自動退避 ＆ 予報連動昇格:**  
  雷接近時や雷予報検知時は、離席スリープの動作をあらかじめ「休止状態（電源OFF＋データ保護）」へ全自動で事前昇格・自動退避させます。
* **簡単セットアップ:**  
  Google マップで指定箇所を右クリックし「緯度, 経度」を `config.json` にコピペするだけで設定完了（住所テキスト入力にも対応）。

### 3. 多彩な通知 ＆ スマホ双方向リモート操作
* **Windows 10 / 11 デスクトップトースト通知 (`desktop_notification`):**  
  普段の作業を邪魔せず、気象・落雷アラート時のみ画面右下にスッとポップアップ通知を表示します（`"weather_only"` 初期値）。
* **Telegram Bot (スマホ双方向リモート制御):**  
  スマホからコマンド（`/sleep`, `/status`, `/weather`, `/server`）を送って遠隔操作したり、スリープ予告通知に返信するだけで「スリープを10分延期」することが可能です。
* **Discord Webhook:**  
  スリープ予告や落雷アラート、遠隔起動用WoLリンクをDiscordチャンネルへ自動配信します。

### 4. cloudwaker 専用 WoL 遠隔起動連携
* **Wake on LAN (Wol) 遠隔起動リンク自動挿入:**  
  Web WoL サービス **[cloudwaker.k7m.f5.si](https://cloudwaker.k7m.f5.si/)** と連携し、通知メッセージ内にワンタップで遠隔起動できるWoLリンクを自動挿入します。

### 5. 電源プロファイル自動切替機能 (任意設定 / 初期値: オフ)
* **ダイナミックな自動パフォーマンス制御:**  
  `config.json` の `"power_plan_control"` 内の `"enabled"` を `true` にすることで有効化できます（初期値: `false` / オフ）。完全放置消灯時 (State 2) には自動で「省電力」へ切り替わり、AI推論・学習時には「高パフォーマンス」、ゲーム時には「究極のパフォーマンス」へ自動昇格します。
* **100% 安全自動復元システム:**  
  マウス操作で復帰した際や、アプリ終了時・異常終了時（`atexit`/`signal`セーフティネット）には、起動時に保存した元の電源プラン (バランス等) へ 100% 確実に自動復元します。
* **安心活用のポイント（OSバグ改善・クリーン設計）:**  
  昔の Windows (Win7/8時代) にあった「電源プラン追加でレジストリが汚れる・ゴミが溜まる」といったOS側の不具合は、現在の Windows 10 / 11 で完全に改善・解消されています。さらに Dual Sleeper では新しい電源プロファイルを一切作成せず、OS標準のプロファイル (GUID) のみを切り替えるため、レジストリを1ミリも汚しません。安心・安全にご活用いただけます。

> [!IMPORTANT]
> **落雷保護機能に関する重要な注意・免責事項**  
> 本アプリの落雷保護・自動休止機能は、気象データに基づく**あくまで補助的なおまけ機能**です。気象APIのデータ更新タイムラグや局地的な落雷の発生により、100%の完全な防御を保証するものではありません。  
> 
> * **物理的防護の推奨:** 雷サージ対策を行う場合は、「雷サージ保護機能付き電源タップ」の利用を推奨いたします。  
> * **雷接近時の根本的対策:** 激しい雷が接近している場合は、アプリの自動処理だけに依存せず、PC・サーバーのそばから離れずにご自身の判断で安全にシャットダウンを行い、**物理的に電源コンセントやLANケーブルを抜く**などの確実な保護対策を行ってください。

## Wake on LAN (WoL) との連携

**Dual Sleeper** は **WoL (Wake on LAN)** と組み合わせることで、リモートPCの省電力運用が可能です。

### Web WoL サービス: cloudwaker.k7m.f5.si
本アプリのWoL連携機能は、Web WoL送信サービス **[cloudwaker.k7m.f5.si](https://cloudwaker.k7m.f5.si/)** に対応しています。

1. **`config.json` への設定方法:**
   `https://cloudwaker.k7m.f5.si/` で生成した起動用URLを `"wol_url"` に設定します。
   ```json
   "wol_url": "https://cloudwaker.k7m.f5.si/?data=..."
   ```
2. **通知からの起動:**
   スリープ予告通知に添付されたWoLリンクをタップすることで、外部からPCを起動できます。

## リリリースノート (Release Notes)

### v1.3.0 (2026-07-29)
* **雷警戒 CAPE しきい値の動的可変設定 (`cape_threshold`: 2500 J/kg):**  
  雷危険の判定基準となる大気不安定エネルギー（CAPE）のしきい値を `config.json` の `"cape_threshold"` から動的設定できるように拡張（デフォルト: `2500 J/kg` 極度に不安定）。
* **実況退避と予兆警戒の二重分離構造:**  
  * **実況即時電源断 (休止):** 遠方の雨での過剰誤作動を防ぐため「自地点ピンポイント 1マス」（CAPE 2500以上 且つ 5.0mm/h ザーザー雨）のみ参照。
  * **予兆警戒 (スリープ20分保持):** 30分前先回り警戒のため従来通り「西広域 13マス（西27km風上スキャン）」を参照。
* **スマート通知 ＆ 12時間 CAPE 予報リスト ＆ 解除予想時刻:**  
  * **落雷予兆警戒発動通知:** 「今後12時間の CAPE 予報リスト」および「警戒解除予想時刻」を自動生成・添付。
  * **スリープ予告通知:** 雷警戒・オートハイバネート有効時のみ CAPE 予報リストを添付し、平常時スリープ通知からは予報リストを隠してシンプルでスッキリした表示へ洗練。
* **`/status` 残りカウントダウン計算の正確性修正:**  
  通常状態 (State 0) でのステータス表示において、無操作残り時間と低通信判定時間を正しく合算した「消灯まで残り: X分X秒」を正確に出力するロジックへ修復。
* **`/weather` レポートへのリアルタイム降水量 (`mm/h`) 併記:**  
  天候が雨・小雨・雷雨等の場合（降水量 > 0.0 mm/h）、天候欄に自動で `(降水量: X.X mm/h)` を見やすく併記する機能を追加。

### v1.2.2 (2026-07-28)
* **Open-Meteo 天気API更新遅れ自動補正アルゴリズム:** ゲリラ豪雨・局地的な夕立・突発的な雷発生時、Open-Meteo のリアルタイムAPIデータ (`current.weather_code`) の更新が数時間遅れて「晴れ」のままになる現象を改善。現在時刻直近 (前後1〜3時間) の予報モデルおよび全マスグリッドを自動スキャンし、直近に雨・雷雨が存在する場合は実況表示へ優先補正反映するロジックを導入。

### v1.2.1 (2026-07-28)
* **`UnboundLocalError` クラッシュバグ緊急修正:** `run_loop()` 関数内における `is_cpu_plan_applied` グローバル変数の宣言漏れによる起動時クラッシュエラーを修正。

### v1.2.0 (2026-07-28)
* **CPU高負荷時プロファイル自動昇格 (`high_performance_on_cpu`):** 動画書き出し・4Kエンコード・大規模コンパイル・巨大ファイル解凍等の CPU 高負荷処理 (CPU 80%以上が 5秒継続) を自動検知し、一時的に「高パフォーマンス」へ全自動で昇格・最高速度処理させる機能を追加（初期値: `false` / オフ）。
* **優先判定ピラミッドの実装:** ゲーム中プレイであっても、裏で重い CPU 計算が発生した場合は「CPU高負荷昇格」を最優先で上書き発動させるエレガントな優先判定構造（`CPU高負荷/AI昇格` ＞ `ゲーム昇格` ＞ `通常運用`）を構築。

### v1.1.10 (2026-07-28)
* **`/status` 電源プラン表示の正確性修正:** ゲーム昇格中 (`ultimate_on_game`) および AI昇格中 (`high_performance_on_ai`) のステータス表示分岐抜けを改修し、OS のリアルタイム適用中電源プラン名（`get_active_power_scheme()`）をダイレクト反映する正確な表示ロジックへ修正。

### v1.1.9 (2026-07-28)
* **VRAM消費量によるAI判定 (`gpu_protect_min_vram_mb`: 500MB):** `python.exe` などの対象プロセスが実際に 500MB 以上の VRAM（GPUメモリ）を消費している場合のみ「AI利用中」と判定するアルゴリズムを導入。Stability Matrix や開発ツール等の「裏で常駐しているだけの Python」を無視し、Forza 等のゲームプレイ中に誤判定される現象を 100% 根絶。

### v1.1.8 (2026-07-28)
* **AI判定しきい値調整 (`gpu_limit_percent`: 40%):** 軽いGPU描画ノイズ (10%〜35%) による高頻度なプロファイルパタパタ切替を抑え込むため、判定しきい値を 40% へ変更。
* **AIプロファイル復帰ヒステリシス延長 (30秒):** AI処理の短い低下による頻回復帰を防止するため、復帰維持時間を 5秒から 30秒へ延長。

### v1.1.7 (2026-07-28)
* **GPU AI保護プロセス判定の厳密化 (誤判定100%排除):** `nvidia-smi` から取得したプロセス名との比較処理を、従来の緩い部分一致 (`in`) からファイル名のみを取り出した厳密な「完全一致 (`==`)」へ改修。Forza Horizon や DLSS (Deep Learning Super Sampling) 稼働ゲーム等の一般 3D ゲームが「Python / AI利用中」と誤判定される不具合を完全解消。

### v1.1.6 (2026-07-27)
* **セキュリティ非干渉設計への純化 (KISS原則):** サインイン要求・パスワード設定等のOSセキュリティ領域へのアプリ側からの変更介入コードを完全撤去。アプリの責務を「電源・スリープ制御」のみに純化し、スリープ直前に元プランへ完全復元することで、ユーザー自身が設定したWindows標準のサインイン挙動を100%素直に反映するクリーン設計へ移行。

### v1.1.4 (2026-07-27)
* **スリープ復帰時ログイン画面要求 回避修正:** 電源プロファイル自動切替有効時、スリープ直前に必ず元の電源プラン（バランス等）へ復元する二重ガードを追加。Windows OS の「省電力プラン標準の復帰時サインイン要求 (CONSOLELOCK)」によってスリープ復帰時にログイン画面へ飛ばされる現象を完全解消。

### v1.1.3 (2026-07-27)
* **AI利用時電源プロファイル自動昇格 (`high_performance_on_ai`):** PyTorch/LLM等のAI推論・学習検知時に「高パフォーマンス」へ自動昇格する機能を追加（初期値: `false` / オフ）。PCIe省電力モードによる生成遅延（t/s低下）を完全に防止。

### v1.1.2 (2026-07-27)
* **ゲーム時電源プロファイル自動昇格 (`ultimate_on_game`):** 操作中 (State 0) にゲーム等のGPU高負荷 (GPU 30%以上) を検知した場合、自動的に「究極のパフォーマンス」プランへ自動昇格する機能を追加（初期値: `false` / オフ）。
* **非対称ヒステリシス保護機能:** パルス通信ノイズによるプロファイルのパタパタ切替（チャタリング）を防止する「3秒継続復元 ✕ 5秒低通信切替」保護ロジックを追加。

### v1.1.1 (2026-07-26)
* **電源プロファイル自動制御機能 (`power_plan_control`):** 完全放置消灯時 (State 2) に自動的に「省電力」プランへ一時切り替え、復帰時や終了時に100%安全に元のプランへ自動復元する機能を追加（初期値: `false` / オフ）。

### v1.1.0 (2026-07-26)
* **13地点気象包囲網:** 日本の気象特性（偏西風・南風）に合わせて西・南側へ最大30km配置した13地点スキャンを実装。
* **Windows 10 / 11 トースト通知:** 画面右下にポップアップ表示する通知機能 (`desktop_notification`: `"weather_only"`) を追加。
* **雷検知モード切替 (`detection_mode`):** 純粋な雷のみ (`"thunder_only"`) と豪雨を含む (`"thunder_and_heavy_rain"`) の選択機能を追加。
* **雷完全通過・解除見込み時間算出:** タイムライン解析による周囲全エリアの通過時刻算出機能を追加。
* **設定ドキュメント更新:** `config.json` の全35パラメータを網羅した一覧表を追加。

### v1.0.0 (2026-07-22) - ファースト・メジャーリリース
