# 🎮 ゲームサーバー保護機能ガイド (Game Server Protection)

Dual Sleeper は、Palworld（パルワールド）、Minecraft、HTTP（Immich等）など、特定のネットワークポートに外部・Tailscale・LAN 経由でプレイヤーやクライアントが接続している間、システムのスリープを無効化する機能を備えています。

---

## ⚙️ 1. 設定方法 (`config.json`)

`config.json` にて、`"game_server_protection"` を有効化し、対象ポート番号（単一数値または配列リスト）を指定します（初期値: 無効）。

```json
"game_server_protection": {
  "enabled": true,
  "ports": [8211, 2283]
}
```

---

## 🌟 2. 動作仕様

1. **モニター消灯中 (State 2) の自動判定**  
   指定したポート（例: パルワールド `8211`, Immich `2283`）にアクティブな外部接続が存在するか物理的に検知します。
2. **プレイヤー接続中 (1名以上)**  
   **スリープを絶対無効化**（タイマーリセット固定）。画面は暗いまま（省エネ維持）ですが、プレイヤーが遊んでいる間は 100% スリープしません。
3. **全員離脱・無人 (0名)**  
   すべての接続が切断された瞬間（＋60秒間ラッチ保護経過後）、自動的にスリープタイマーが再開し、**5分後に全自動でスリープして節電** します。

---

## 🌐 3. Tailscale ＆ LAN 接続完全対応

* Windows の `psutil` および `netstat` エンジンにより、通常のアクティブ IP 接続だけでなく、**Tailscale VPN 経由（`100.x.x.x`）や LAN ネットワーク経由の接続も 100% 確実に検出** します。
* 60 秒間のアクティブラッチ機能を搭載しているため、HTTP (Webアクセス) のように一瞬でソケットが切断されるアクセスであっても、スリープ誤爆を起こしません。
