# ⚡ 電源プロファイル自動制御ガイド (Power Plan Control)

> [!NOTE]
> 本機能は、現状であまり活用されていない Windows の電源プロファイルを有効利用した **試験的機能** です。お使いの環境に合わせて自由にカスタマイズしてご活用ください。

Dual Sleeper は、Windows OS 標準の電源プラン（GUID）を状況に応じてダイナミックに自動切替し、処理性能の最大化と放置時の極限節電を自動で両立させます。

---

## ⚙️ 1. 設定方法 (`config.json`)

`config.json` の `"power_plan_control"` 内の `"enabled"` を `true` に変更することで有効化されます（初期値: `false` / 無効）。

```json
"power_plan_control": {
  "enabled": true,
  "default_power_plan": "",
  "restore_on_exit": true,
  "power_saver_on_idle_monitor_off": true,
  "ultimate_on_game": true,
  "high_performance_on_ai": true,
  "high_performance_on_cpu": true,
  "cpu_heavy_threshold_percent": 80,
  "cpu_heavy_duration_seconds": 5
}
```

### ⚙️ 設定オプション
* **`default_power_plan`**:  
  復元先の標準電源プランの固定指定（`""` でアプリ起動時のプランを自動判定）。  
  * `""` (初期値): 起動時のアクティブプランを自動取得。万が一起動時に「省電力」だった場合は自動で「バランス」を安全保存。
  * `"バランス"`, `"高パフォーマンス"`, `"究極"` 等を指定すると、起動時の状態に関わらず、常にそのプランを元プランとして復元固定します。

---

## 🌟 2. 自動切替の動作モード

1. **完全放置消灯時 (State 2) の全自動節電 (`power_saver_on_idle_monitor_off`)**  
   操作から離脱してモニターが消灯した瞬間、自動的に OS 標準の **「省電力」プロファイル** へ切り替え、CPUのクロックと電圧を物理的に抑制して消費電力を大幅カットします。復帰時には安全に元の電源プランへ自動復元します。
2. **GPUゲーム中の高パフォーマンス昇格 (`ultimate_on_game`)**  
   ゲーム起動時（GPU使用率 30%以上）に自動的に **「究極のパフォーマンス（または高パフォーマンス）」** プランへ自動昇格し、フレームレートの低下を防ぎます。
3. **AI学習・推論時の昇格 (`high_performance_on_ai`)**  
   `python.exe` や `llama-server` 等が VRAM 4GB 以上を消費して AI 処理を行っている場合、自動的に **「高パフォーマンス」** プランへ昇格させます。
4. **CPU高負荷処理時の昇格 (`high_performance_on_cpu`)**  
   動画エンコード、大規模コンパイル、**Windows Update のインストール (`TiWorker.exe`等)** で CPU 80% 以上が 5 秒間継続した場合、自動的に **「高パフォーマンス」** プランへ昇格させます。

---

## 💡 3. 実践チューニングヒント (節電 ＆ パフォーマンス最大化)

Windows の「電源オプション」から各プロファイル内の詳細設定値を切り替えることで、より適切に節電しつつ PC の力を発揮できる可能性があります。

### 🍃 省電力プロファイル (放置時の節電)
* **おすすめ設定:**  
  * プロセッサの電源管理 ➔ **プロセッサの最大の状態: `70%`**
  * プロセッサの電源管理 ➔ **プロセッサの最小の状態: `0%`**
* **効果:**  
  放置中の CPU 発熱と電力消費を物理的に抑制するのに非常に効果的な可能性があります。その他、ディスプレイ消灯時間や放置を見越した省電力向けの設定値に切り替えるとより効果的です。

### 🚀 高パフォーマンスプロファイル (AI向け)
* **おすすめ設定:**  
  * プロセッサの電源管理 ➔ **プロセッサの最小の状態: `99%`**
  * プロセッサの電源管理 ➔ **プロセッサの最大の状態: `100%`**
* **効果:**  
  AI 向けプロファイルとして利用する場合、CPU を即座にハイスピード待機状態にしておくことで、AI モデルやチェックポイント（Safetensors等）の読み込みが若干スムーズになる可能性があります。

### 🎮 究極のパフォーマンスプロファイル (ゲーム向け)
* **おすすめ設定:**  
  * プロセッサの電源管理 ➔ **プロセッサの最小の状態: `99%`**
  * プロセッサの電源管理 ➔ **プロセッサの最大の状態: `99%`**
* **効果:**  
  ゲーム向けプロファイルとして利用する場合、最大のプロセッサの状態を `99%` に設定すると、CPU のターボブースト（過度なクロック跳ね上がり）をオフにしながら、FPS 維持には十分な性能が出ることも多いです。発熱やファンの騒音を抑えつつ安定してプレイできるため、競技設定などで極限まで FPS にこだわりたい方でなければ非常におすすめの設定です。
